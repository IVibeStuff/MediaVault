## MediaVault 1.7.2

Maintenance release — bug fixes only, no new features.

### Library & Scanning
- Fixed TV series not being identified when the series name came from a season-pack folder (e.g. `Show S04 1080p … DDP5 1 H 264`): bare season tags and space-separated codec tags are now stripped.
- Episode files named only by number (`E01.mkv`, `01 - Title.mkv`) now take the series name and season from their folder instead of being misnamed or filed as movies.
- Junk filter now uses token-based matching instead of substring matching. Titles like *Extraction* or *The Big Short* are no longer misidentified as junk and silently removed from the library.
- Keyword hits are ignored for files that look like real releases (year tag + minimum size); folder-based junk detection requires an exact folder-name match (e.g. `Extras/`, `Samples/`).
- Custom junk keywords are now additive to the defaults.
- Offline drive protection: files on an unmounted or unreachable watched folder (USB drive, NAS) are no longer treated as deleted at startup.
- Item IDs are now collision-safe path hashes.
- Hiding a folder now also removes TV shows and episodes under it.
- Hidden items no longer reappear after a rescan.
- Fixed a case-sensitivity mismatch that could create duplicate TV show entries when adding folders.

### Metadata & Remapping
- Fixed remapped titles being reverted by "Refresh metadata".
- Failed poster downloads (404/500) are no longer cached as images.
- API and image requests now have timeouts, HTTP status checks, and relative-redirect handling.

### My List / Watchlist
- Marking an item as Watched now moves it from "New & Upcoming" to Watched instead of showing it in both.
- Dismissed/watched "New & Upcoming" flags no longer re-activate on every release check; they return only for a genuinely new season or release date.
- Marking a movie as seen from the TV Guide applies the same behaviour.

### Other
- Fixed accumulating document-level event listeners when opening detail overlays.
- Added missing `assets/icon.svg` required for the Windows installer build.

### Notes
- Items hidden in earlier versions may reappear once after the next rescan — re-hide them once.
- TV shows previously added under a garbled name keep that name after rescanning. Use Options → Remap title to fix them.
